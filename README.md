# Mirror Sculpt

Sculpt one object with your fingers and watch a second answer through a
mirror map, a formula, or a photo with depth.

**Open it:** https://noahsadler21.github.io/mirror-sculpt/

**Put it on your home screen:** open the link in Safari, tap Share, then
*Add to Home Screen*. On Android, open it in Chrome and choose *Install app*.
Once installed it works with no signal.

- One finger on the left object sculpts (Push, Carve, Smooth); on empty space it orbits.
- Two fingers orbit and pinch. Hold two fingers still to draw a selection box.
- **Picture** projects a photo onto the object; add a depth map to scale it.
- **⋯** opens scans (PLY, OBJ, XYZ), picks colours, and saves OBJ files.

This repository holds only the built app: one HTML page, its manifest, a
service worker and icons. It is the phone version of a mirror lab in a
larger, private project.
